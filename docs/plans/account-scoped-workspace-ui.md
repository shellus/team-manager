# 账号内 Workspace 管理重构计划

状态：已实施并通过自动化与运行实例验收。

## 产品边界

- Workspace 保持独立领域实体和数据库关系，但不作为一级产品管理维度。
- 删除独立 Workspace 列表、详情路由和导航入口，不提供旧路由兼容。
- 账号详情的 Workspace 标签使用 `workspaceId` query 在该账号的多个 Workspace 间切换；未指定或无效时选择账号关系中的第一个。
- 所有 Workspace 读写操作以当前账号为执行上下文。当前账号不是 owner/admin 时，成员、邀请、设置和账单刷新等管理操作不可用。
- Workspace 凭证只展示和操作当前 `Account × Workspace` 的凭证，不展示同空间其他账号凭证。
- 正式成员和待接受邀请合并为一个运营列表，保留各自真实来源、状态和对应操作。
- 不设 Workspace 概览、客户席位独立页面或 Workspace 活动日志入口；客户资料嵌入成员与邀请列表。套餐、续费、计费席位、金额、支付方式和发票集中在账单视图。
