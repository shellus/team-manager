状态：已完成。

> 本计划记录当时已完成的账号内客户资料恢复范围。后续已接受的待认领席位和公开自助管理入口以 [`固定 GPT 席位自助管理计划`](./fixed-gpt-seat-self-service-management.md) 为准，尚未实施。

## 产品边界

- `SeatSlot` 继续作为 Workspace 下独立的客户运营资料，不并入 Membership 或 Invitation 表。
- 账号详情的 Workspace 成员列表按 `Workspace + 规范化邮箱` 合并成员、邀请和客户资料；没有远端关系的历史客户资料仍作为“未关联”行显示。
- 成员列表不分页，账号与备注、状态、租客信息分别使用两行单元格；没有备注时省略第二行。关系、角色和席位合并为状态列，联系方式、价格和到期日合并为租客信息列；Workspace 所有者行不显示租客信息和操作。
- 角色与席位、租客信息和邀请分别使用弹窗表单；邀请请求可同时保存租客信息，租客字段复用同一表单组件。
- 成员和邀请只显示一个列表级最后刷新时间，不在每行重复快照时间。
- 保留黄色警示语义的“释放”“撤销”和红色危险语义的删除空置客户资料；不恢复复制公开链接、管理员人工换号或独立客户席位页面。
- 到期提醒使用显式 `expireReminder` 开关，默认开启；只有开关开启且存在到期日时才参与提醒，既有席位迁移为开启。
- `expireRemove` 继续表示到期后是否尝试移除远端关系；关闭时到期后只停用本地客户资料。开启时最多尝试 3 次，最终失败后保留关系和客户资料、停止自动重试并通过到期通知策略告警，不降级成本地停用。
- 到期提醒日程固定由 `seat_expiration` 策略定义；实际投递使用已启用且配置完整的通知渠道。
