# 运营可见性恢复实施计划

状态：已实施并通过联合验收。付费个人套餐互切仍受 GAM 已记录的上游协议边界限制，界面不提供虚假入口。

## 目标

统一账号 PostgreSQL 重构必须保留旧版成熟 UI 的运营效率。结构化数据、API 或后台任务存在，不代表用户可以看懂、找到或处理对应业务。本计划恢复账号生命周期、任务进度、订阅账单、母号概览、席位概览、Team 订单、通知和风险提示，同时维持统一 Account、Workspace 和 Membership 领域模型。

## 产品裁决

### 账号列表

- 列表继续只展示账号、分组、主套餐、续费/到期、GAM 和操作，不恢复 Workspace 数、凭证数、Session 是否存在、可管理空间或普通成员；双席位主套餐使用单个 `双席位 n/2` Tag 表示套餐和代表 Workspace 的席位占用。
- 主套餐生命周期和双席位占用使用同一查询来源：个人付费套餐优先，否则使用命中的 owner Workspace；不缓存或双写到 `accounts`。
- `willRenew=true` 显示“续费”，`willRenew=false` 显示“到期”；只有日期但续费语义未知时显示“有效至”。Team 子号和 Free 不显示日期。
- 同类 owner Workspace 多于一个时，取最早的未来续费时间；没有未来日期时取最近的已知日期，并明确标记过期。
- 封号继续用账号字段错误徽标表示。同步失败、登录态无效和任务失败也只在账号字段显示异常摘要，不新增常态能力列。
- GAM 与 Profile 运行继续使用两枚互斥 Checkbox 表达所有/是/否；不恢复限额、Workspace、凭证或 Session 筛选。
- 搜索实际覆盖邮箱和账号备注，必须与界面提示一致；账号不保存独立显示名。

### 操作进度

- 不新增“操作中心”、全局任务页或导航入口。
- 已有账号的注册、开通、支付、Business 和其他自动化操作在对应账号行展示最新活动操作摘要，包括阶段、进度、等待动作、失败原因和完成结果。
- 列表发起操作后必须立即保留 Operation，并持续刷新对应账号摘要；详情和列表复用同一进度展示与控制组件。
- 尚未创建 Account 的注册任务作为临时账号行显示在账号列表中，使用目标邮箱、目标分组和注册状态；成功收敛后自动被正式账号行替代。
- 页面刷新、离开后返回和开发进程重启后仍可从账号列表找到未完成或失败任务。

### JSON 与日志

- 除 Session JSON 编辑器外，任何页面都不提供原始 JSON 查看器、调试抽屉或原文下载入口。
- 订阅、账单、额度、订单、通知、操作和活动日志只显示结构化业务字段与可读文本。
- 完整上游载荷继续保存在 PostgreSQL 日志/快照或文件制品中，供后端排查；不因移除 UI 原文入口而删除证据。
- HTTP trace、rrweb 和凭证 JSON 继续遵循文件制品边界，但 UI 只展示可读日志、录制回放、元数据和明确业务动作，不展示或编辑 JSON 原文。凭证替换、重新授权和投放使用结构化业务流程。

## 实施范围

### A. 共享合同与查询投影

- 为账号运营摘要增加主套餐生命周期、登录健康、最新异常和最新活动操作。
- 主套餐生命周期由普通 PostgreSQL View 投影，不增加账号缓存列。
- 提供未绑定账号的注册任务列表投影，按目标分组参与账号列表展示。
- 账号搜索只使用邮箱和账号备注。
- 为个人订阅、账单、母号概览、席位概览、Team 订单、通知和活动日志定义明确共享类型，前端不得继续消费数据库 `selectAll()` 裸对象。

### B. 账号列表与详情

- 增加“续费/到期”列。
- 账号字段显示封号、登录无效、同步失败和任务失败徽标；正常状态不制造噪声。
- 账号行和临时注册行展示操作阶段、进度和失败恢复入口，不增加导航页面。
- 列表和详情发起套餐操作后共用 Operation 展示闭环。
- 详情概览删除 Session 是否存在、可管理空间、普通成员、Workspace/凭证数量等无价值摘要，替换为主套餐生命周期、登录健康、最近同步和异常。
- 个人空间结构化展示套餐、续费、有效期、生效时间、额度窗口、个人资料和快照更新时间；取消续费按钮按订阅状态启用。

### C. 订阅与账单

- 建立个人与 Workspace 共用的订阅、金额、发票、支付方式、账单主体和时间展示组件。
- 展示 upcoming invoice、应付/剩余金额、项目、数量、单价、账期、预计扣款时间、发票小计、税费、在线发票和 PDF。
- Workspace 账单提供刷新入口和 ChatGPT 账单管理链接；不提供原始 JSON 查看或下载。
- 所有金额、状态、日期和套餐代码使用统一中文标签与格式。
- 修复个人空间 API 返回通用 snapshot 覆盖已规范化订阅字段的问题。

### D. 母号概览、席位概览与 Workspace

- 母号概览是顶部导航中的独立一级页面，只以管理账号未封号的双席位 Business Workspace 为卡片粒度，按精确到秒的续费/到期时间正序排列；卡片标题单行显示直接状态、账号备注和灰色管理账号，不显示 Workspace 名称、套餐标签或重复状态。“母号”是运营称呼，不是数据实体。
- 席位概览是顶部导航中的独立一级页面，只以 SeatSlot 为卡片粒度，按到期日正序排列；展示占用邮箱、席位类型、客户信息、到期、价格、Workspace 和可管理账号关系。Membership、Invitation 和固定容量不是租客席位，不补虚拟空位。
- 两个页面不合并为运营总览或页内标签；均使用带填充背景的响应式卡片 Grid，不使用表格。卡片短字段采用无独立背景的双列信息组压缩高度，筛选与页码进入 URL，每页数量按页面保存到 localStorage。
- 不恢复脱敏开关。
- Workspace 列表展示自身续费时间和风险筛选。
- Workspace 概览展示 SeatSlot 与远端成员/邀请的一致性告警。
- Workspace 增加结构化活动日志；账号和 Workspace 活动日志不显示原始 JSON。

### E. Team 订单

- 后端输出类型化维护摘要和订单摘要，不向前端暴露数据库蛇形字段。
- 恢复维护池、运行中、可用订单和需关注统计。
- 恢复账号/Workspace 搜索、状态筛选、Checkout 打开/复制、剩余有效期、下次运行、自动重试、配置摘要和 Workspace 历史订单。
- 筛选、展开项和编辑状态写入 URL。

### F. 通知、代理与凭证

- 通知设置恢复提前提醒天数、触发时间和 Webhook、飞书、Telegram、企业微信结构化表单；保留测试、投递历史和有限重试。
- 修复席位提醒固定七天且每分钟执行、忽略配置的问题；调度和筛选使用已保存设置。
- 换 IP 共用弹窗使用国家选项，明确 SID 更新语义，约束 ASN 与州/城市的互斥组合。
- 账号凭证显示 Workspace 名称而非内部 UUID；额度窗口显示重置时间、状态和快照时间。
- Workspace 凭证支持进入账号、刷新额度及执行已有凭证管理动作，复用账号凭证组件。

### G. 文档与完成定义

- 修正 `unified-account-product-completion.md` 中以裸表或 JSON 代替业务页面的错误完成勾选。
- 更新 README 和使用说明中的最终可见入口。
- 不修改统一 Account、Workspace、Membership、SeatSlot 和 Credential 领域边界。

## 回滚与数据边界

新增数据库对象使用可逆 migration。业务事实继续以现有 PostgreSQL 表和文件制品为准；UI 重建不重写历史账单、操作、通知、凭证或活动日志。回滚应用代码不得删除已生成的 Operation、快照或文件制品。
